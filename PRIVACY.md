# Privacy

Budget Planner stores account names, balances, income, expenses, scenarios, settings, and net-worth
history as JSON files in its configured local data directory. The application has no analytics,
advertising, user accounts, or cloud synchronization, and the user interface does not load remote
fonts or other third-party web content.

Data leaves the application only when a user exports a backup or deliberately exposes the local
service through additional network infrastructure. Backup files contain the complete financial
dataset in readable JSON and should be stored and transferred securely. Deleting the application
does not necessarily delete its data directory or exported backups.

This statement describes version 1.3.1 of the source code. A distributor that adds telemetry,
licensing, crash reporting, updates, hosting, or payment integrations must update this notice.
